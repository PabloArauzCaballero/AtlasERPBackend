# Carpeta `src/common/persistence`

Contiene abstracciones compartidas de persistencia.

## Responsabilidad

Centraliza contratos y utilidades de acceso a datos reutilizables, sin mezclar reglas de negocio.

## Qué no debe ir aquí

- Services de negocio.
- Controllers.
- Validaciones HTTP.
- Consultas específicas de un dominio concreto.
