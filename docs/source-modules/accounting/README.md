# docs

Documentación técnica del módulo: arquitectura, flujos, endpoints, Postman, auditoría y progreso.

## Carpetas

- `architecture/`: arquitectura y flujos contables.
- `endpoints/`: documentación HTTP y OpenAPI.
- `postman/`: colección para pruebas manuales.
- `audit/`: auditoría de despliegue y hardening SAP-like.
- `progress/`: informe de progreso técnico.
