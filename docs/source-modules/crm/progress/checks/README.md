# Logs de validación

Contiene los logs generados durante la auditoría final:

- `type-check.log`
- `build.log`
- `lint.log`
- `unit-tests.log`
- `e2e-tests.log`
- `npm-audit-production.log`
- `prettier-check.log`

Estos logs permiten verificar qué comandos se ejecutaron y con qué resultado antes de empaquetar el entregable.
