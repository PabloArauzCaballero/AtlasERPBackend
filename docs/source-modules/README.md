# Documentación fuente de módulos

Esta carpeta conserva la documentación original de los tres backends antes de integrarlos.

- `crm`: documentación original de CRM/Ventas B2B.
- `accounting`: documentación original del módulo contable.
- `ads`: documentación original del módulo de publicidad externa.

La documentación integrada y vigente para ejecución del backend se encuentra en `docs/endpoints`, `docs/architecture`, `docs/postman` y `docs/progress`.
